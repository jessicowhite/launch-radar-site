Privacy Policy

Last updated: November 18, 2026

Launch Radar ("the tool") is a personal, single-user application. This policy explains what data it accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • Google OAuth token for the channel owner's own account (YouTube upload and read access to that one channel), used only to upload videos to it and confirm the channel ID.
  • Upload results: the video ID and status returned by YouTube for each upload.
  • The tool does not access, collect or store data about any other YouTube user.

How data is used, stored and shared

  • Tokens and upload records are stored only on the owner's own computer, in local files.
  • No data is sold, shared with third parties, or used for advertising.
  • No cookies or tracking are used on this website or by the tool.

Retention and deletion

Stored API data is refreshed or deleted within 30 days, as required by YouTube's developer policies. The owner can delete all stored data at any time by deleting the tool's local data folder.

Revoking access

Access can be revoked at any time on the Google security settings page.

Contact

Questions or removal requests: open an issue at github.com/jessicowhite/launch-radar-site/issues.
